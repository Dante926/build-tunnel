1、将域名托管至 Cloudflare 

创建 Cloudflare 账号; 导航栏 -> 域名 -> 概览 -> "添加域名" -> "连接一个域名"  -> 完成添加域名; 跳转至计划选择; 选择免费计划 -> 进入到域名 DNS 管理; 下划至底部, 选择继续前往激活; -> 跳转至更新名称服务器页; 将 Cloudflare 分配的两个 Cloudflare 名称服务复制; -> 回到**<font style="color:rgb(2, 6, 23);background-color:rgba(255, 255, 255, 0.9);">DigitalPlat; 选择域名列表; 点击域名进入到域名管理页; 找到"使用其他名称服务器"项; 点进"使用其他名称服务器", 并将复制的两个Cloudflare 名称服务器粘贴进待填项中; 完成后更新名称服务器; 回到 Cloudflare 的名称服务器管理界面中, 下划找到"我已更新名称服务器"; 等待 Cloudflare 更新注册表; 刷新界面会看到 "您的域现在受 Cloudflare 保护"</font>**

2、在 Cloudflare 中建立内网穿透隧道  
①侧边导航栏找到"联网"并点击;  
②点击"Tunnel";  
③点击"Create Tunnel"; 输入任意"Tunnel name"; 点击"Create Tunnel"; 进入到 Create Tunnel 详情页  
④选择Docker 操作系统; 复制"Run tunnel with Docker"指令; docker run cloudflare/cloudflared:latest tunnel --no-autoupdate run --token <TUNNEL_TOKEN>
