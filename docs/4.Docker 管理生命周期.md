上一章节我们拿到了以 Docker 作为安装环境的 docker 指令, 接下来我们需要 dockercompose 文件来管理 cloudflare 以及 mcpjungle

①mcpjungle 的意义: 用来作为统一的 mcp 注册网关, 已经暴露网关的 http 端点供外部服务使用  
②创建一个文件夹(按照自己的风格命名) tunnel/ , 创建 /.env , 定义变量 TUNNEL_TOKEN = "<上一章节得到的 TUNNEL_TOKEN>"  
创建 /docker-compose.yaml 写入:

```yaml
services:
  cloudflared:
    image: cloudflare/cloudflared:latest
    container_name: cf-tunnel
    restart: unless-stopped
    command: tunnel --no-autoupdate run --token ${TUNNEL_TOKEN}
    
```

运行 

```shell
docker compose config # 查看环境变量是否正常载入
docker compose up -d  # 启动容器
docker compose ps 		# 查看当前 compose 对应容器	
```

如果cloudflare 容器启动成, 此时回到cloudflare -> networking -> tunnel -> domain 能看到该域名的 tunnel 状态应为 Healthy ,或通过 docker logs <容器名或容器ID> --tail 50 查看是否有存在 Registered tunnel connection xxx 的日志, 有则成功将 cloudflare 与 Cloudflare 边缘网络建立连接。

③更新 docker-compose 为:

```yaml
services:
  cloudflared:
    image: cloudflare/cloudflared:latest
    container_name: cf-tunnel
    restart: unless-stopped
    command: tunnel --no-autoupdate run --token ${TUNNEL_TOKEN}
    depends_on: 
      - mcpjungle

  db:
    image: postgres:17
    container_name: mcpjungle-db
    environment:
      POSTGRES_USER: mcpjungle
      POSTGRES_PASSWORD: mcpjungle
      POSTGRES_DB: mcpjungle
    volumes:
      - db_data:/var/lib/postgresql/data
    healthcheck:
      test: [ "CMD-SHELL", "PGPASSWORD=mcpjungle pg_isready -U mcpjungle" ]
      interval: 10s
      timeout: 5s
      retries: 5
    restart: unless-stopped

  mcpjungle:
    image: ghcr.io/mcpjungle/mcpjungle:latest-stdio
    container_name: mcpjungle-server
    environment:
      DATABASE_URL: postgres://mcpjungle:mcpjungle@db:5432/mcpjungle
      SERVER_MODE: development
      MCP_SERVER_INIT_REQ_TIMEOUT_SEC: 30
    ports:
      - "127.0.0.1:8080:8080"
    volumes:
      - /Users/admin/Desktop/dante926:/host:rw  # 这里的路径将作为 mcpjungle 可操作的根路径, 例如宿主机的 /dante926 将作为 mcpjungle 可操作的 /host 根目录
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped

volumes:
  db_data:

```

运行  docker compose up -d 更新 docker compose 并启动容器, 启动成功无报错后进入到 [http://127.0.0.1:8080](http://127.0.0.1:8080/) 将会看到 mcpjungle dashboard   
③为 mcpjungle 注册一个可操作文件的 mcp；创建/tunnel/mcp/filesystem.json，填入：

```json
{
  "name": "filesystem",
  "transport": "stdio",
  "description": "project files read/write",
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "/host"],
  "session_mode": "stateless"
}
```

在 /tuunel 终端运行: 

```shell
curl -X POST http://127.0.0.1:8080/api/v0/servers \
  -H 'Content-Type: application/json' \
  -d @mcp/filesystem.json
```

进入到 [http://127.0.0.1:8080](http://127.0.0.1:8080/) 能看到有 filesystem 注册记录，执行验证

```shell
curl -s http://127.0.0.1:8080/api/v0/servers
```

看到输出 filesysteam.json 则成功
