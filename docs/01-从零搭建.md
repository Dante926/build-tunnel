# 从零搭建 "Local ChatGPT"

把本机的一个文件夹通过 MCP 协议暴露给 Web 版 ChatGPT 读写。

整个过程不开任何公网入站端口：本地 `cloudflared tunnel` 主动向 Cloudflare 边缘拨出连接，
Cloudflare 顺着这条已建立的连接把请求送回来。

## 必要条件

| 条件                 | 用途                                       |
| -------------------- | ------------------------------------------ |
| VPN 网络             | 访问 DigitalPlat、Cloudflare、ChatGPT      |
| GitHub 账号          | 注册并绑定 DigitalPlat、Cloudflare         |
| ChatGPT 账号         | 调用暴露出来的 MCP 端点                    |
| visa｜PayPal｜万事达 | 用来开通 `Cloudflare Zero Trust Free Plan` |

## 链路

```
ChatGPT（云端）
  │  HTTPS
  ▼
Cloudflare 边缘        证书终结 + 身份验证
  │  ingress 转发规则
  ▼
cloudflared            常驻出站连接
  │  compose 内网
  ▼
mcpjungle              把 stdio 的 MCP 包成 HTTP 端点
  │  stdio 子进程
  ▼
filesystem MCP server
  ▼
本机文件夹
```
