# 绑定域名与创建隧道

## 1. 将域名托管至 Cloudflare

创建 Cloudflare 账号，然后：

1. 导航栏 → **域名** → **概览** → **添加域名** → **连接一个域名** → 完成添加域名
2. 跳转至计划选择 → 选择**免费计划**
3. 进入域名 DNS 管理 → 下拉至底部 → 选择**继续前往激活**
4. 跳转至更新名称服务器页 → 复制 Cloudflare 分配的两个名称服务器
5. 回到 **DigitalPlat**：
   - 选择域名列表 → 点击域名进入域名管理页
   - 找到 **使用其他名称服务器** → 点进去
   - 把复制的两个 Cloudflare 名称服务器粘贴进待填项 → 更新名称服务器
6. 回到 Cloudflare 名称服务器管理界面 → 下拉找到 **我已更新名称服务器**
7. 等待 Cloudflare 更新注册表。刷新界面后会看到「您的域现在受 Cloudflare 保护」

## 2. 在 Cloudflare 中建立隧道

1. 侧边导航栏找到 **联网** 并点击
2. 点击 **Tunnel**
3. 点击 **Create Tunnel** → 输入任意 **Tunnel name** → 点击 **Create Tunnel** → 进入 Create Tunnel 详情页
4. 选择 Docker 操作系统 → 复制 "Run tunnel with Docker" 指令：

```sh
docker run cloudflare/cloudflared:latest tunnel --no-autoupdate run --token <TUNNEL_TOKEN>
```

下一章会把它从命令行参数挪进 `.env` 文件，由 docker compose 注入。
