我们需要做两件事, ①在 Cloudflare 中暴露出一个 public hostname 并与tunnel建立连接 ②为tunnel添加ingress 转发规则  
1、步骤: Zero Trust 面板 → Networks → Tunnels → 你的隧道 → Published application routes → Add。

|  字段 | 值 |
| --- | --- |
| Subdomain(可选) | mcp |
| Domain | 你的域名 |
|  Path(可选) | 空 |
| Type | HTTP |
| URL | mcpjungle:8080 |
